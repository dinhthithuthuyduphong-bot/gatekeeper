# Repository Navigation & Search
- Jinja2 source code is located in the `src/jinja2/` directory.
- Use `grep -rn "pattern" src/jinja2/` to find relevant classes or functions. For example, `grep -rn "class TemplateData" src/jinja2/`.
- **Trust your search results**: If `grep` returns a file and line number (e.g., `src/jinja2/nodes.py:1205`), use `sed -n '1200,1230p' src/jinja2/nodes.py` to read that exact section. Do not repeatedly run the same `grep` command if you already have the answer.
- Key modules: 
  - `environment.py`: Core environment and compilation coordination.
  - `compiler.py`: Generates Python source code from the AST. If a template raises `SyntaxError`, it usually means the compiler generated invalid Python code.
  - `nodes.py`: AST nodes for the template (e.g., `Const`, `TemplateData`).
  - `optimizer.py`: Handles constant folding and AST optimization.

# Code Editing Strategy
- Avoid using inline `sed` or string `.replace()` for complex multi-line edits, as they frequently lead to duplicated code or mismatched replacements.
- **Best Practice for Editing**: Use a Python script to rewrite a specific range of lines based on the exact line numbers you found. Example:
  ```bash
  python3 -c "
  with open('src/jinja2/compiler.py', 'r') as f: lines = f.readlines()
  # Replace lines 125 through 145 (inclusive). 
  # Note: lines list is 0-indexed, so line 125 is index 124.
  lines[124:145] = [
      'def has_safe_repr(value: t.Any) -> bool:\n',
      '    if value is None:\n',
      '        return True\n',
      '    return False\n'
  ]
  with open('src/jinja2/compiler.py', 'w') as f: f.writelines(lines)
  "
  ```
- **Always verify your edits**: After editing, use `sed -n '120,150p' src/jinja2/compiler.py` to ensure your indentation is correct and no duplicate functions were created.
